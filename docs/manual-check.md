평가 데이터 전체의 평균 오차(94대)보다 큰 것은, 모델이 약한 평일 출퇴근 시간 3행(3/30 8시, 5/22 8시, 5/30 18시)을 일부러 포함했기 때문이다.

## 잘 맞은 경우

- **한산한 새벽·밤 시간:** 10/14 새벽 2시(+55), 1/11 밤 9시(+39), 7/3 자정(-90). 대여 수 자체가 적고 패턴이 일정해서 오차가 100대 이내였다.
- **주말 저녁:** 6/17(일) 19시는 실제 2,481대, 예측 2,398대로 오차가 -83대(약 3%)였다. 주말 여부를 입력에 넣은 효과가 보인다.
- **추운 날:** 1/11 기온 -12.4°C에서 실제 162대, 예측 201대로 낮은 수요를 잘 맞혔다.

| 5/30(수) 18시 | 3,251 | 2,878 | -373 | 평일 퇴근 피크. 실제 피크가 모델 예측보다 더 높다 |

- **평일 출퇴근 피크는 적게 예측**하고, **공휴일 출근 시간은 많이 예측**하는 경향이 있다.
- 결과 화면의 "보통 ±94대" 범위를 벗어난 경우가 10행 중 6행이다. 화면의 예상 범위는 평균 오차일 뿐이고, 피크·공휴일에는 범위가 더 넓다는 점을 사용자에게 알려야 한다.

## 개선이 필요한 포인트

1. **요일 정보 추가:** 지금은 주말 여부(0/1)만 쓴다. 요일(월~일)을 넣으면 평일 안에서도 요일별 차이를 배울 수 있다. 사용자 입력은 늘지 않는다(날짜로 계산).
2. **공휴일 데이터 보강:** 1년치 데이터에는 공휴일이 적다. 여러 해 데이터를 추가로 수집하면 공휴일 패턴을 더 잘 배울 수 있다.
3. **출퇴근 피크 보정:** 평일 8시·18시를 표시하는 입력(예: 출퇴근 시간 여부)을 추가하거나, 피크 시간 오차를 따로 측정해 개선 여부를 확인한다.
4. **결과 화면 안내 개선:** 피크 시간이나 공휴일을 입력하면 "이 시간대는 오차가 클 수 있음" 같은 안내를 함께 보여 준다.
5. **여러 해 데이터 수집:** 지금은 2017-12~2018-11의 1년치뿐이다. 서울 열린데이터광장의 공공자전거 대여 이력을 추가하면 연도별 변화와 특수한 날을 더 잘 반영할 수 있다.
